# AGENZ V4.0 — Visual Style

## Core Evolution

V4.0 evolves AGENZ from:

- cinematic luxury restraint
- AI-noir aesthetics
- over-designed editorial perfection

into:

**emotionally believable intensity.**

The system is no longer built around:

- filters
- darkness
- atmospheric grading
- "premium aesthetics"

Instead, it is built around **observed modern life**, heightened strategically through:

- typography
- pacing
- composition
- emotional contrast
- cultural awareness
- selective visual aggression

The world should feel: alive, youthful, human, real, stylish, ambient, and emotionally current.

## Core Emotional Signature

AGENZ should feel like a **culturally intelligent creative operator** moving through modern life while documenting ambition, internet culture, AI systems, and emotional reality.

The emotional tone must feel:

- observational
- creatively alive
- naturally stylish
- emotionally aware
- internet-native
- quietly ambitious
- youthful
- expressive
- believable
- emotionally immediate

The brand should create **connection before authority.**

> "Calm worlds with loud interruptions."

The base world remains:

- realistic

## Typography System

> **The display is heavy condensed grotesk, not Instrument Serif.** Verify against `brand/references/agenz_ref_*.png` before writing prompts — the reference posts show the lived practice. Instrument Serif appears, but only for accent lines (italic emphasis, gold-color taglines, "ONLY 9 FELT HUMAN" register), never as the primary loud headline.

### Display Grotesk — Anton (or Druk Condensed Heavy / Bebas Neue equivalent)

Purpose: the loud interruption. Headlines, statement lines, "stop the thumb" type.

Always all-caps. Heavy weight. Condensed proportions. Tight leading. Sits flush left, grid-anchored — never magazine-centered.

The loudness comes from **scale, weight, and confidence** — not from decoration. Color is usually Soft Ivory `#F4F1EB` on a darker photographic background, or Washed Charcoal `#2C2B2A` on paper.

Vendored to: `brand/fonts/Anton-Regular.ttf`.

### Accent Serif — Instrument Serif

Purpose: a single emphasized line inside a headline, or a soft tagline that softens a loud condensed-grotesk block. Often italic. Often in an accent color (Warm Sunlight Beige, gold, faded denim).

Never used for the primary headline. Never as the masthead. Treat as the violin under the bass.

Vendored to: `brand/fonts/InstrumentSerif-Regular.ttf`, `InstrumentSerif-Italic.ttf`.

### Grotesk System — Geist

Purpose: subheads, body copy, the line that follows the headline and explains it. Structure, clarity, internet-native rhythm.

Clean, confident, human. **Never corporate.**

Vendored to: `brand/fonts/Geist-Regular.ttf`, `Geist-Medium.ttf`.

### Technical Mono — JetBrains Mono

Purpose: masthead chrome at the corners (`FIELD NOTE №07`, `AGENZ CREATIVE SYSTEMS`, `V4.0`, coordinates, timestamps). Section labels (`INSIDE:`). Section dividers.

Always small. Always uppercase for chrome. Lowercase for inline annotations. Subtle, never dominant.

Vendored to: `brand/fonts/JetBrainsMono-Regular.ttf`.

## Composition (mandatory for every slide)

- **Aspect:** 1080×1350 (4:5 IG portrait). No squares.
- **Photo layer:** the photograph fills the full 4:5 canvas. No paper-texture backgrounds for cover slides — those go on the editorial pivot slide only.
- **Mastheads live at the corners,** not centered. Two corners minimum:
  - Top-left or top-right (`FIELD NOTE №NN  /  AGENZ CREATIVE SYSTEMS  /  V4.0` split across corners)
  - Bottom-right almost always carries a small mono marker (`V4.0`, coordinates, timestamp, or section index)
- **Headline anchors to one corner** (typically lower-left or upper-left over shadow areas of the photo). Never centered.
- **No badge stamps.** The "01 / 06" rule index is small mono in a corner, not a stamp-style numbered seal.
- **Logo placement:** the AGENZ monkey mark, when used, sits in a corner at ~5–7% canvas width. It is composited from `brand/logo/Logo2.png` directly — never described to an image model in words.

## Why typography + logo are composited, not generated

Image models hallucinate letters, misspell words, and invent brand marks. Every AGENZ slide must use the *exact* fonts and the *exact* logo file. The pipeline therefore:

1. Generates only the **ambient photograph** through the image model — no text, no logo in the model's job.
2. Composites the masthead, headline, subhead, badge, and logo on top in Python using the vendored font files and `brand/logo/*.png`.

This is the only way to guarantee correct spelling, correct fonts, and correct brand identity on every slide.

## Composition Rules

Prioritize:

- breathing room
- asymmetrical realism
- environmental storytelling
- emotional framing
- accidental beauty
- layered observation
- human movement
- ambient negative space

Occasionally interrupt calmness with:

- oversized type
- bold crops
- aggressive scale
- anti-design placement
- visual density spikes

This creates **emotionally believable tension.**
